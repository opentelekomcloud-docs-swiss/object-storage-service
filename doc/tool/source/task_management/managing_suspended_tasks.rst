Managing Suspended Tasks
========================

Prerequisites
-------------

There are suspended tasks in the list.

Procedure
---------

#. Log in to OBS Browser+.

#. In the navigation pane, click **Task Management**.

#. Choose the **Suspended** tab.


   .. figure:: /_static/images/en-us_image_0000002683558504.png
      :alt: **Figure 1** Suspended task list

      **Figure 1** Suspended task list

#. (Optional) Select one or more tasks and click **Run** (|image1|). The executed tasks will appear on the **Queuing** tab or the **Pending** tab.

#. (Optional) Select one or more tasks and click **Delete** (|image2|).
